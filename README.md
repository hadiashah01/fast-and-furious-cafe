# Fast & Furious Cafe — Sialkot

A responsive Next.js App Router website for Fast & Furious Cafe, Circular Road, Sialkot.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Use `npm run lint` and `npm run build` to validate the project.

## Pages

- `/` — cafe overview, verified combo, menu highlights, standards, and location.
- `/menu` — verified menu highlights with live search and category filters.
- `/deals` — verified Furious Duo Feast, Solo Speed Combo, and Midnight Roll Bundle.
- `/about` — cafe approach, service options, and location information.
- `/contact` — address, hours, contact actions, and directions.

Menu highlights and deal prices are based on the supplied verified information. Cafe hours are daily 3:00 PM – 1:00 AM; schedule subject to confirmation.
